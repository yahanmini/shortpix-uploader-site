ShortPix-Uploader 개인정보처리방침

시행일: 2026년 11월 3일

1. 사용하는 정보

ShortPix-Uploader는 사용자가 Google 계정으로 연결한 YouTube 채널에 대해 다음 일에만 YouTube Data API를 사용합니다.

  • 사용자가 고른 영상 업로드
  • 영상의 공개 상태와 예약 공개 시각 설정·조회
  • 채널 이름과 프로필 이미지 조회

2. 저장 위치

Google이 발급한 인증 토큰과 작업 기록은 사용자 본인의 PC에만 암호화해 저장합니다. 개발자나 다른 서버로 보내지 않습니다.

3. 제3자 제공

받은 정보를 판매하거나 다른 사람·회사에 제공하지 않으며, 광고에 사용하지 않습니다.

4. Google API 서비스 사용자 데이터 정책

Google API에서 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 연결 해제와 삭제

언제든 Google 계정 → 타사 앱 및 서비스에서 ShortPix-Uploader의 접근을 해제할 수 있습니다. 업로더에서 채널을 삭제하면 저장된 토큰도 함께 지워집니다.
